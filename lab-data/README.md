# Dados sintéticos para o exercício

Este diretório contém materiais inteiramente fictícios que podem ser entregues ao
participante como contexto inicial de uma avaliação local.

`synthetic-credential-exposure.csv` simula um pequeno recorte consolidado de fontes
antigas. O conteúdo mistura possíveis credenciais atuais, valores desatualizados e
identidades que podem não existir. Não há coluna de validade nem gabarito.

Todos os domínios usam `.local`. Não acrescente dados reais e não utilize o material
contra qualquer sistema fora desta instância local da Vaulta.
